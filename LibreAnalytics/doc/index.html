Guide d'installation et de tracking

LibreAnalytics est une alternative française et open source à Google Analytics : un pixel de tracking de 4 Ko, sans cookies, conforme au RGPD, hébergeable chez soi en PHP 8.2+ et MySQL. L'installation se fait en trois étapes : création d'un compte gratuit, ajout du site pour récupérer votre ID de tracking, puis copier-coller d'une seule ligne de script dans le <head> de vos pages. Comptez environ 2 minutes, sans carte bancaire.

Tutoriel API LibreAnalytics

La documentation couvre l'API publique étape par étape : récupération de votre clé API, construction de l'URL de requête, exemples d'appels et réponses en JSON et CSV, gestion des erreurs, et intégrations (dashboards HTML/JS personnalisés, tableurs, et même un microcontrôleur ESP32). L'API est idéale pour les développeurs qui veulent réutiliser leurs statistiques de trafic ailleurs.

Paramètres UTM et analyse de trafic

Le guide utilisateur détaille le suivi des paramètres UTM (source, medium, campagne), la lecture du tableau de bord (vues, visiteurs uniques, pages/session, temps moyen), la gestion multi-sites depuis un seul compte, ainsi que la géolocalisation, les sources de trafic et les appareils de vos visiteurs.

FAQ, glossaire et roadmap

La documentation complète inclut une FAQ (gratuité, RGPD, installation, API), un glossaire de l'analytique web et la roadmap du projet. Le code source et l'historique des versions sont disponibles sur GitHub (licence MIT).

LibreAnalytics est-il vraiment gratuit ?

Oui. Le logiciel est libre (MIT) : l'instance gael-berru.com propose un plan gratuit (1 site, 1000 vues/mois) et l'auto-hébergement via un fork du dépôt GitHub est gratuit et illimité.

LibreAnalytics utilise-t-il des cookies ?

Non. Aucun cookie n'est déposé, le script pèse environ 4 Ko, et les données sont hébergées en Europe. Le projet est pensé comme une alternative souveraine et conforme au RGPD face à Google Analytics.
